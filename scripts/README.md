# Utility Scripts

## 📁 Contents

| Script | Description |
|--------|-------------|
| `setup.sh` | Development environment setup |
| `seed-users.sh` | Initialize user config file |
| `healthcheck.sh` | Container health check |

## 🚀 Usage

```bash
# Make scripts executable
chmod +x scripts/*.sh

# Run setup
./scripts/setup.sh

# Seed users
./scripts/seed-users.sh
```
